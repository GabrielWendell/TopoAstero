# Notebooks

Notebooks are explanatory clients of tested package functions. They may not contain the only copy
of a method, parameter, result, or figure. Before release, clear incidental outputs, execute in the
locked environment, and ensure every input/output is in a manifest or compact release directory.

`00_repository_tour.ipynb` demonstrates the data-free Stage 0 smoke calculation.

`03_rudy_classical_baseline.ipynb` is an executed audit client for the Stage 3 tables and figures.
The one-command workflow remains authoritative and the notebook runs offline from compact results.

`04_simulation_lab.ipynb` is an executed, read-only audit client for governed run
`TA-S04-LAB-R001`. The package and one-command Stage 4 workflow remain authoritative.
