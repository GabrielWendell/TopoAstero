# Stage 5 redundancy and ablation report

The 72-cell development panel contains **1** feature pairs with `|Spearman rho| >= 0.85`. `results/stage5/redundancy_pairs.csv` also reports a Gaussian-copula mutual-information proxy; this is a descriptive continuous-association summary, not proof that arbitrary nonlinear dependence is absent.

Six-fold ridge ablations compare identical classical controls with and without each compact topological block. Incremental R2 ranges from **-0.047** to **0.226**. These values guide feature pruning only; they are not population performance estimates. PSD prominence equivalence, delay phase sensitivity, and echelle graph-only distinctness remain formal Stage 6-8 tests.
