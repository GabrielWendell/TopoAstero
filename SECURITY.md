# Security and sensitive information

The core project uses public astronomical data and contains no personal data. Do not commit API
tokens, credentials, private review correspondence, unpublished holdout labels, or machine paths
that reveal secrets. Report a suspected credential or supply-chain exposure privately to the
project lead before opening a public issue.

Raw FITS products are referenced through manifests and checksums rather than committed. Treat the
final holdout assignment and authorization record as access-controlled research material until its
registered opening.
