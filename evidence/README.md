# Stage 1 evidence

This directory is the machine-readable evidence layer for Stage 1. Human-readable synthesis lives
under `docs/literature/` and `docs/benchmarks/`; acceptance evidence lives under
`reports/stage1/`.

- `literature/`: physics, classical-pipeline, mathematical-TDA, astronomy-TDA, and
  hypothesis-to-baseline matrices.
- `benchmarks/`: the 66-star LEGACY population sheet, the Rudy target sheet, 42 published Rudy
  mode frequencies, identity record, and source provenance.
- `search/`: dated, reproducible novelty queries and their outcomes.
- `references/`: claim-level reference audit and the clean Stage 1 BibTeX library.

CSV cells that contain multiple identifiers use semicolons. A blank uncertainty means “not
reported”, never zero. The benchmark specification distinguishes authoritative benchmark rows
from context-only worked-example or incompletely attributed catalog values.
