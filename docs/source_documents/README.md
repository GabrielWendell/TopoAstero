# Project-source documents

This directory preserves the proposal, detailed agenda, Gantt roadmap, and bibliography used to
implement Stage 0. `SOURCE_DOCUMENT_CHECKSUMS.csv` records the exact source bytes. The detailed
agenda pages 11-12 are the controlling Stage 0 specification; the proposal and roadmap supply the
hypotheses, data tiers, critical path, risk controls, and software architecture.

Future edits to these planning documents require a new filename/version and a change-log entry;
they do not silently rewrite the frozen registries.
